公版书是什么？古登堡计划与 Standard Ebooks 怎么选

公版书可以免费合法下载，但古登堡和 Standard Ebooks 风格完全不同。这篇讲清楚区别，帮你选对下载源。

“公版书”（Public Domain）指版权保护期届满、进入公有领域的作品。在中国，作者去世 50 年后作品进入公有领域；美国是 95 年。公版书意味着：任何人都可以自由复制、分享、改编，无需授权、无需付费。这就是为什么《红楼梦》《莎士比亚全集》《战争与和平》都能免费下载。

但同样是公版书，不同平台差异很大。最常用的两个英文公版书站，风格完全不同。

Project Gutenberg：量大管饱的原始文本

古登堡计划 1971 年创立，是全球最古老的电子书库，收录 7 万+ 本。

优点：

  • 数量碾压一切同类站点，几乎所有英文公版书都能找到
  • 格式全：EPUB、Kindle、HTML、纯文本
  • 无 DRM、无登录、无限制

缺点：

  • 排版朴素，基本没有封面和版式设计
  • 校对质量靠志愿者，个别书有 OCR 错误

适合：快速找文本、做检索、当素材。学术引用、全文检索场景它最强。

Standard Ebooks：重新设计过的阅读体验

Standard Ebooks 是 2015 年启动的志愿者项目，把古登堡等来源的公版书重新排版、校对、加封面、统一字体与版式，产出的 EPUB 质量接近商业出版物。

优点：

  • 排版是公版书界的标杆，电子墨水屏阅读体验一流
  • 元数据规范，封面精美，收藏党福音
  • 提供 EPUB、AZW3（Kindle 直装）、KEPUB（Kobo）

缺点：

  • 收录量只有 1000+ 本，远少于古登堡
  • 纯英文，没有中文内容

适合：真正"读"书、在意阅读体验的人。用 Kindle 或平板读英文原著，选它基本不会失望。

其他公版书来源

  • 维基文库：中文公版古籍与文献，可自由使用
  • LibriVox：公版书的有声版，2 万+ 本志愿者朗读
  • Loyal Books：分类友好的公版书有声+文本站

怎么选？

需求推荐
快速下载、全文检索、当素材Project Gutenberg
认真阅读、在意排版Standard Ebooks
中文古籍维基文库
听书LibriVox / Loyal Books

建议组合使用：用古登堡找书、检索，用 Standard Ebooks 享受阅读。两个都是免费、无 DRM、无版权风险的优质来源。

延伸阅读：正版电子书获取指南。
